# The Word You'd Delete From the Dictionary

A [make.fun](https://make.fun/bounty/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2) entry.

## The entry

**delete**

One word: the single word this entry would erase from the dictionary
forever. The joke is the word itself, and it lands the instant you read
it — `delete` is the very verb doing the erasing. Delete `delete` and
deletion itself is gone: you can never delete anything again, not even
the word that made it possible.

## How it works

`main.py` (Python 3.13) writes the word to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set), validated
against the gate: 1–77 characters of UTF-8 text, exactly one word,
nothing added around it.

## Run

```sh
python3 main.py
```
